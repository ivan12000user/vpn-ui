# VPN UI

Unified self-hosted Web UI for:

- WireGuard
- AmneziaWG

## Architecture

The finished application runs entirely on the VPN server.

Development machines, VPN peers and GitHub are not runtime dependencies.

## Current stage

v0.1 foundation:

- Rust / Axum
- common Web UI
- WireGuard section
- AmneziaWG section
